shamash

Rust → WebAssembly20 songs, 30 s eachLive demo

Ask for a song the way you would in voice chat, and watch the request go through the bot.

Wake word, Understand and Match run the bot's own Rust code, compiled to WebAssembly.

Speaking to it works in Firefox, Chrome and Edge. Brave, Helium and other browsers without a speech service can't use the 🎤, so type your request there instead.

🎤 uses your browser's speech recognition, which in Chrome sends the audio to Google. The real bot transcribes on its own machine.
